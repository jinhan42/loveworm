# 권장 센서 목록 및 배선 가이드

## 1. 열교환기 (Heat Exchanger)

### 파이프 표면 온도 측정
| 항목 | 내용 |
|------|------|
| 변환기 모델 | **CWT-PT100S** |
| 프로브 타입 | PT100 파이프 클램프온 (표면 부착형) |
| 통신 | RS485 Modbus RTU |
| 측정 범위 | -50°C ~ 200°C |
| 전원 | DC 12~24V |
| Modbus 레지스터 | 40001 (0x0000): 온도 × 10 (signed int16) |
| 슬레이브 주소 | 1 (기본값, 변경 가능) |

### 물 유량 측정
| 항목 | 내용 |
|------|------|
| 모델 | **TUF-2000M** (초음파 클램프온) |
| 방식 | 비접촉 초음파, 파이프 외부 클램프 |
| 적용 배관 | DN15 ~ DN100 (설정에 따라 확장) |
| 통신 | RS485 Modbus RTU |
| 전원 | DC 24V |
| Modbus 레지스터 | 1~2: 순간 유량 float32 (LPM) |
| 슬레이브 주소 | 2 |
| TUF-2000M 메뉴 설정 | 메뉴62: 9600,N,0,1 / 메뉴63: Modbus_RTU / 단위: L/min |

## 2. 이머전 탱크 (Immersion Tank)

### 냉각유 온도 측정 (상층 / 하층)
| 항목 | 내용 |
|------|------|
| 변환기 모델 | **CWT-PT100S** × 2 |
| 프로브 타입 | PT100 침지형 (SUS316 스테인리스 재질, 오일 호환) |
| 측정 범위 | -50°C ~ 200°C |
| 통신 | RS485 Modbus RTU |
| Modbus 레지스터 | 40001 (0x0000): 온도 × 10 (signed int16) |
| 슬레이브 주소 | 상층=3, 하층=4 (각각 다르게 설정) |

> ⚠️ 프로브 재질 확인: 냉각유(3M Novec, 광유 등)와 화학적 호환성 확인 필수

### 냉각유 유량 측정
| 항목 | 내용 |
|------|------|
| 모델 | **TUF-2000M** (초음파 클램프온) |
| 방식 | 비접촉 초음파, 파이프 외부 클램프 |
| 통신 | RS485 Modbus RTU |
| Modbus 레지스터 | 1~2: 순간 유량 float32 (LPM) |
| 슬레이브 주소 | 5 |
| TUF-2000M 메뉴 설정 | 유체 파라미터: 오일 점도/음속 설정 필요 |

## 3. RS485 배선 구성

```
Raspberry Pi (USB-RS485 변환기)
     │
     ├── CWT-PT100S (열교환기 온도, 슬레이브 1)
     ├── TUF-2000M  (열교환기 유량, 슬레이브 2)
     ├── CWT-PT100S (이머전 탱크 상층 온도, 슬레이브 3)
     ├── CWT-PT100S (이머전 탱크 하층 온도, 슬레이브 4)
     └── TUF-2000M  (이머전 탱크 유량, 슬레이브 5)
```

> RTU 방식: 모든 장비를 RS485 버스에 직렬 연결, 종단 저항 120Ω 양끝 설치
> TCP 방식: RS485-Ethernet 게이트웨이 사용 (각 게이트웨이 IP 설정)

## 4. TUF-2000M Modbus 레지스터 상세

| 레지스터 주소 | 데이터 타입 | 설명 |
|--------------|------------|------|
| 1~2 | float32 | 순간 유량 (설정 단위) |
| 3~4 | float32 | 유속 (m/s) |
| 5~6 | float32 | 누적 유량 + |
| 9~10 | float32 | 열량 |
| 33~34 | float32 | 입력 온도 (°C) |
| 35~36 | float32 | 출력 온도 (°C) |

## 5. CWT-PT100S Modbus 레지스터 상세

| 레지스터 주소 | 데이터 타입 | 설명 |
|--------------|------------|------|
| 0x0000 | signed int16 | 온도 × 10 (253 = 25.3°C) |
| 0x0001 | uint16 | 상태 레지스터 |
